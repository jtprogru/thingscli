# Архитектура

## Раскладка

```
cmd/things/main.go      — точка входа
internal/cli/           — cobra-команды и флаги
internal/things/        — клиент Things 3
  client.go             — обёртка над osascript
  locale.go             — таблица локалей + рантайм-проба + кэш
  applescript.go        — общие AS-хелперы и экранирование
  models.go             — Todo / Project / Area / ListKey
  ops.go                — операции чтения и записи
```

Cobra-обвязка отделена от пакета `things`, чтобы клиент можно было переиспользовать как библиотеку.

## Протокол вывода

AppleScript не умеет в JSON. Клеить `jsonEscape` внутри AS-скрипта (как в исходной zsh-версии) — два уровня экранирования и хрупко. Вместо этого AS отдаёт записи через ASCII-разделители:

- `\x1e` (RS, ASCII 30) — между записями
- `\x1f` (US, ASCII 31) — между полями записи

Эти байты не встречаются в пользовательском контенте задач. Go читает поток, режет по разделителям и сам сериализует через `encoding/json`. Экранирование — один раз, на стороне Go.

## Резолв локали

Things 3 локализует имена встроенных списков под язык интерфейса. `list "Inbox"` сработает только в английском интерфейсе; в русском нужно `list "Входящие"`. Хардкод одного набора имён привязывает тулу к одному языку.

CLI решает это в три шага:

1. **Таблица.** `internal/things/locale.go` содержит `builtinLocales` — набор записей `{lang, inbox, today, upcoming, ...}` для известных языков.
2. **Проба.** При первом использовании один `osascript`-вызов перебирает кандидатов «Входящих» и возвращает первое имя, которое Things реально резолвит. Этот язык становится активным.
3. **Кэш.** Совпавшая запись пишется в `~/.cache/thingscli/locale.json` с таймстампом. Дальнейшие запуски пропускают пробу 30 дней. `--refresh-locale` форсит перепробу; `--lang <code>` обходит кэш и берёт таблицу указанного языка напрямую.

Если Things использует язык, которого в таблице нет, — проба возвращает пусто и пользователь получает понятную ошибку. Добавление поддержки — одна строка в `builtinLocales`.

## Встраивание AppleScript

Хелперы (`pad`, `dateISO`, `parseDate`, `todoRecord`) живут в одной константе `asHelpers`, которая прицепляется к каждому скрипту, где они нужны. Каждый скрипт — небольшой самодостаточный блок AS, собранный конкатенацией Go-строк, без шаблонизаторов и вложенного экранирования.

Единственное экранирование — для AppleScript-литералов в двойных кавычках: `\` → `\\`, `"` → `\"`. Всё остальное (мультибайтный UTF-8, контрольные символы кроме `\x1e`/`\x1f`) проходит насквозь.

## Идентификация

Задачи адресуются по стабильному `id` Things (тот же идентификатор использует URL-схема `things:///`). По имени — никогда: имена не уникальны и редактируются.

## Чем эта штука не является

- Не обёрткой над `things:///`. URL-схема только для записи и не умеет в чтение/поиск/lookup — всё идёт через AppleScript.
- Не sync-слоем. Локальной базы нет, каждая команда — живой AppleScript-вызов.
- Не деструктивной. Безвозвратного удаления нет. Самая жёсткая операция — `trash`, и она обратима из самого Things.
