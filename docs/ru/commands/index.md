# Обзор команд

Команды делятся на две группы по контракту вывода:

- **Чтение** — печатают JSON в stdout (массив для списков, объект для `show`/`locale`). Безопасно пайпить в `jq`. См. [Чтение](read.md).
- **Запись** — печатают одну короткую строку статуса (например, `DONE <id>`) и возвращают ненулевой exit на ошибке. См. [Запись](write.md).

## Глобальные флаги

| Флаг                | Назначение                                                               |
|---------------------|--------------------------------------------------------------------------|
| `--lang <code>`     | Принудительно использовать конкретный язык для встроенных списков.       |
| `--refresh-locale`  | Перепробовать Things и переписать локаль-кэш.                            |
| `--pretty`          | Форматировать JSON отступами (только для команд чтения).                 |

## Идентификация задач

Все команды записи принимают **id** задачи первым аргументом — стабильный идентификатор, который команды чтения возвращают в поле `id`. По имени задачу не адресуем: имена не уникальны и могут меняться.

```sh
ID=$(things inbox | jq -r '.[0].id')
things done "$ID"
```

## Коды возврата

- `0` — успех.
- `1` — ошибка приложения (Things вернул ошибку, список не найден, id не найден). Сообщение уходит в stderr.
- `2` — ошибка использования (не то число аргументов, конфликтующие флаги).
