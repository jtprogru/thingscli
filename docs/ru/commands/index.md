# Обзор команд

Команды делятся на две группы по контракту вывода:

- **Чтение** — по умолчанию печатают компактную таблицу: три колонки (`ID`, `NAME`, `STATUS`) для списков задач, блоки key:value для одиночных объектов (`show`, `locale`), по одной строке на тег для `tags`. Флаг `--json` переключает на исходную JSON-форму для пайплайнов. См. [Чтение](read.md).
- **Запись** — печатают одну короткую строку статуса (например, `DONE <id>`) и возвращают ненулевой exit на ошибке. На команды записи `--json` не влияет. См. [Запись](write.md).

## Глобальные флаги

| Флаг                | Назначение                                                               |
|---------------------|--------------------------------------------------------------------------|
| `--lang <code>`     | Принудительно использовать конкретный язык для встроенных списков.       |
| `--refresh-locale`  | Перепробовать Things и переписать локаль-кэш.                            |
| `--json`            | Печатать сырой JSON вместо таблицы (только команды чтения).              |
| `--pretty`          | Форматировать JSON отступами. Имеет смысл только вместе с `--json`.      |

## Идентификация задач

Все команды записи принимают **id** задачи первым аргументом — стабильный идентификатор. В табличном выводе показываются только первые 8 символов id для читаемости; полный id доступен через `--json` или через `things show <prefix>`. По имени задачу не адресуем: имена не уникальны и могут меняться.

```sh
ID=$(things inbox --json | jq -r '.[0].id')
things done "$ID"
```

## Коды возврата

- `0` — успех.
- `1` — ошибка приложения (Things вернул ошибку, список не найден, id не найден). Сообщение уходит в stderr.
- `2` — ошибка использования (не то число аргументов, конфликтующие флаги).
