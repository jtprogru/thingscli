# Чтение

По умолчанию команды печатают компактную таблицу. Флаг `--json` переключает на структурированную форму (JSON-массив для списков, объект для `show`/`locale`, плоский список строк для `tags`). Комбинация `--json --pretty` даёт JSON с отступами.

## Встроенные списки

Семь встроенных списков Things, доступных по каноническому имени независимо от языка интерфейса:

| Команда            | Что возвращает                                                       |
|--------------------|----------------------------------------------------------------------|
| `things inbox`     | Задачи во Входящих.                                                  |
| `things today`     | Задачи на сегодня.                                                   |
| `things upcoming`  | Запланированные на будущее («Завтра» / Upcoming).                    |
| `things anytime`   | В любое время.                                                       |
| `things someday`   | Когда-нибудь.                                                        |
| `things logbook`   | Журнал (выполненные/отменённые).                                     |

По умолчанию — таблица из трёх колонок:

```
ID        NAME                          STATUS
5ZhX1arE  Оплатить аренду               open
WavUHfP2  Прочитать пост про ядро Linux  open
```

Колонка `ID` — первые 8 символов стабильного идентификатора Things, этого хватает глазу, но не полный id. Через `--json` получаешь полную запись:

```json
[
  {
    "id": "5ZhX1arERehyn2JXGzd8Mk",
    "name": "Оплатить аренду",
    "notes": "С карты #2",
    "status": "open",
    "tags": "home,P1",
    "due": "2026-07-01",
    "start": "",
    "project": "",
    "area": "Home"
  }
]
```

## Произвольный список

```sh
things list "<локализованное-имя>"
```

Используй, когда нужен список, которого нет среди семи встроенных, или когда хочешь обратиться к Things прямо по его текущему отображаемому имени.

## Проекты, области, теги

```sh
things projects     # таблица: ID | NAME | STATUS
things areas        # таблица: ID | NAME
things tags         # по одному тегу на строку
```

С `--json` — соответственно `[{id,name,area,status}, ...]`, `[{id,name}, ...]` и `["P1","P2",...]`.

## Содержимое проекта

```sh
things project "<Имя проекта>"
```

## Поиск

```sh
things search "<подстрока>"
```

Возвращает задачи, в имени которых встречается подстрока (правила регистрозависимости — на стороне Things). Ищет по всем спискам.

## Одна задача

```sh
things show <id>
```

По умолчанию — блок key:value со всеми полями:

```
ID       5ZhX1arERehyn2JXGzd8Mk
Name     Оплатить аренду
Status   open
Tags     home,P1
Due      2026-07-01
Start
Project
Area     Home
Notes    С карты #2
```

С `--json` — один объект `Todo`. Ошибка, если задачи с таким id нет.

## Что определилось как локаль

```sh
things locale
```

Резолвленная таблица локали — полезно при отладке, когда команда встроенного списка возвращает не то, что ожидалось.

```
Lang      ru
Inbox     Входящие
Today     Сегодня
Upcoming  Завтра
Anytime   В любое время
Someday   Когда-нибудь
Logbook   Журнал
Trash     Корзина
```

С `--json` — структурированная форма.
