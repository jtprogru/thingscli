# Чтение

Все команды печатают JSON.

## Встроенные списки

Семь встроенных списков Things, доступных по каноническому имени независимо от языка интерфейса:

| Команда            | Что возвращает                                                       |
|--------------------|----------------------------------------------------------------------|
| `things inbox`     | Задачи во Входящих.                                                  |
| `things today`     | Задачи на сегодня.                                                   |
| `things upcoming`  | Запланированные на будущее («Завтра» / Upcoming).                    |
| `things anytime`   | В любое время.                                                       |
| `things someday`   | Когда-нибудь.                                                        |
| `things logbook`   | Журнал (выполненные/отменённые).                                     |

Каждая выдаёт JSON-массив объектов `Todo`:

```json
[
  {
    "id": "5ZhX1arERehyn2JXGzd8Mk",
    "name": "Оплатить аренду",
    "notes": "С карты #2",
    "status": "open",
    "tags": "home,P1",
    "due": "2026-07-01",
    "start": "",
    "project": "",
    "area": "Home"
  }
]
```

## Произвольный список

```sh
things list "<локализованное-имя>"
```

Используй, когда нужен список, которого нет среди семи встроенных, или когда хочешь обратиться к Things прямо по его текущему отображаемому имени.

## Проекты, области, теги

```sh
things projects     # [{id,name,area,status}, ...]
things areas        # [{id,name}, ...]
things tags         # ["P1","P2","home", ...]
```

## Содержимое проекта

```sh
things project "<Имя проекта>"
```

## Поиск

```sh
things search "<подстрока>"
```

Возвращает задачи, в имени которых встречается подстрока (правила регистрозависимости — на стороне Things). Ищет по всем спискам.

## Одна задача

```sh
things show <id>
```

Один объект `Todo`. Ошибка, если задачи с таким id нет.

## Что определилось как локаль

```sh
things locale
```

Возвращает резолвленную таблицу локали — полезно при отладке, когда команда встроенного списка возвращает не то, что ожидалось.

```json
{
  "lang": "ru",
  "inbox": "Входящие",
  "today": "Сегодня",
  "upcoming": "Завтра",
  "anytime": "В любое время",
  "someday": "Когда-нибудь",
  "logbook": "Журнал",
  "trash": "Корзина"
}
```
