# Старт

## Требования

- macOS (Things 3 — только под mac; CLI использует `/usr/bin/osascript`).
- Установленный Things 3, хотя бы раз запускавшийся.
- Go 1.26+, если собираешь из исходников.

## Установка

**Через Homebrew (рекомендуется):**

```sh
brew install --cask jtprogru/tap/things
```

**Из исходников:**

```sh
go install github.com/jtprogru/thingscli/cmd/things@latest
```

**Из релизного архива:** скачай с [GitHub Releases](https://github.com/jtprogru/thingscli/releases), распакуй, положи `things` в директорию из `PATH`.

## Первый вызов

```sh
things locale
```

Это запускает рантайм-пробу. CLI одним AppleScript-вызовом перебирает известные имена «Входящих» из таблицы локалей и берёт первое, которое Things реально знает. Результат пишется в `~/.cache/thingscli/locale.json` на 30 дней.

Если язык твоего Things в таблице ещё не описан — проба вернёт пустоту, увидишь понятную ошибку. Заведи issue со списком имён семи встроенных списков на твоём языке, добавим.

## Переопределения

| Флаг                | Эффект                                                                  |
|---------------------|-------------------------------------------------------------------------|
| `--lang <code>`     | Пропустить авто-детект, использовать таблицу указанного языка.          |
| `--refresh-locale`  | Сбросить кэш и перепробовать.                                           |
| `--json`            | Печатать сырой JSON вместо таблицы (только команды чтения).             |
| `--pretty`          | Форматировать JSON отступами. Имеет смысл только с `--json`.            |

Известные коды: `en`, `ru`, `de`, `fr`, `es`, `it`, `ja`, `zh-Hans`, `pt-BR`, `nl`.

## Проверка

```sh
things projects
things today
```

Если обе команды возвращают таблицу (хоть и пустую) — всё работает. Если `osascript` ругается — убедись, что Things 3 установлен и был запущен хотя бы раз.
